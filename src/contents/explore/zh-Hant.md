## poi 是什麼

poi 是以 Electron 與 React 開發的開源艦隊 Collection 瀏覽器，支援 Windows、macOS 和 Linux。除了內建工具，也可以透過外掛擴充功能。

遊戲通訊遵循 Electron 所使用的 Chromium 的行為，原則上不提供修改收發封包的功能。

## 基本功能

- 擷取遊戲畫面、快速重新整理、靜音，以及調整遊戲解析度。
- 設定 HTTP、SOCKS5 和 PAC 代理伺服器，轉送遊戲資料。
- 一覽提督資訊、資源、艦隊與基地航空隊狀態。
- 查看遠征、入渠、建造與任務進度。任務的詳細說明由「任務信息」外掛提供。
- 接收建造、遠征、入渠與疲勞恢復通知，出擊前檢查船位、裝備容量與鎖船狀態。大破進擊提醒由「未卜先知」外掛提供。
- 自訂介面配置、主題、圖示與艦娘頭像。
- 使用多語言介面。
- 透過遊戲資料介面與外掛 API 開發擴充功能。
