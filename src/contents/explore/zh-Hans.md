## poi 是什么

poi 是基于 Electron 与 React 开发的开源舰队 Collection 浏览器，支持 Windows、macOS 和 Linux。除了内置工具，还可以通过插件扩展功能。

游戏通信遵循 Electron 所使用的 Chromium 的行为，原则上不提供修改收发数据包的功能。

## 基本功能

- 截取游戏画面、快速刷新、静音，以及调整游戏分辨率。
- 配置 HTTP、SOCKS5 和 PAC 代理，转发游戏数据。
- 一览提督信息、资源、舰队与基地航空队状态。
- 查看远征、入渠、建造与任务进度。任务的详细描述由「任务信息」插件提供。
- 接收建造、远征、入渠与疲劳恢复通知，出击前检查船位、装备容量与锁船状态。大破进击提醒由「未卜先知」插件提供。
- 自定义界面布局、主题、图标与舰娘头像。
- 使用多语言界面。
- 通过游戏数据接口与插件 API 开发扩展功能。
