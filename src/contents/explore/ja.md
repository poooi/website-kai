## poi とは

poi は Electron と React で開発された、Windows・macOS・Linux 対応のオープンソース艦これブラウザーです。基本機能に加え、プラグインで機能を拡張できます。

ゲームの通信は Electron に搭載された Chromium に準じ、原則として送受信パケットを改変する機能は提供しません。

## 基本機能

- スクリーンショットの撮影、ゲームの再読み込み、ミュート、解像度の変更。
- HTTP・SOCKS5・PAC によるプロキシ設定とゲームデータの転送。
- 提督情報、資源、艦隊、基地航空隊の情報を一覧表示。
- 遠征、入渠、建造、任務の状況を確認。任務の詳細な説明は「任務情報」プラグインが提供します。
- 建造・遠征・入渠・疲労回復の通知と、出撃時の艦船・装備の空き枠やロック状況の確認。大破時の進撃警告は「未卜先知」プラグインが提供します。
- レイアウト、テーマ、アイコン、艦娘の画像をカスタマイズ。
- 多言語のインターフェースに対応。
- ゲームデータとプラグイン API を使った機能拡張。
